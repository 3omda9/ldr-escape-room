# Co-Op LDR Escape Room 🧩💻

A real-time, multi-device collaborative escape room web app built for long-distance couples. 

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend & Sync:** Firebase Realtime Database (CDN)

## Features
* **Asymmetric Gameplay:** Separates UI views dynamically into a "Guide" (laptop interface) and a "Player" (mobile D-pad controller).
* **Real-time State Sync:** Uses Firebase database listeners to instantly sync player positioning across devices with zero latency.
* **Interactive Stages:** Includes password decryption vaults, blind grid maze navigation, mathematical server ciphers, and a collaborative multi-device drawing canvas.
